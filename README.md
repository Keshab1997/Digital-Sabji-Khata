## ✨ Features

- 📒 Daily transaction entries
- 👤 Customer balance tracking
- 🧮 Automatic calculations
- 🇧🇩 Bengali-friendly UI

## 🛠️ Built With

- **JavaScript — app logic**
- **HTML/CSS — simple, clean interface**

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/Keshab1997/Digital-Sabji-Khata.git
# Install dependencies
npm install
# Start the app
npm run dev
```

🔗 **Try it live:** [https://digital-sabji-khata.vercel.app](https://digital-sabji-khata.vercel.app)
